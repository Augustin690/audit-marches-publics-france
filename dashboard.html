Méthodologie

Sources de données

  • DECP — Données Essentielles de la Commande Publique via data.economie.gouv.fr (702 918 marchés disponibles, 10 000 analysés)
  • BOAMP — Bulletin Officiel des Annonces de Marchés Publics (1,6M avis, 3 000 analysés)
  • API Sirene — Annuaire des Entreprises pour l’enrichissement des profils fournisseurs
  • UGAP / LDLC — Prix commerciaux de référence pour les fournitures

Système de scoring (0–100)

Base = 50 points

+15 pts → Marché passé sans publicité ni mise en concurrence

+15 pts → Une seule offre reçue (fournisseur unique)

+10 pts → Fournisseur ayant 3+ marchés sans concurrence (captivité)

+ 5 pts → Fournisseur présent sur 10+ marchés (concentration)

+ 5 pts → Catégorie COTS (comparable aux prix commerciaux)

+ 5 pts → Montant dans la fourchette 50k–5M € (accessible)

- 10 pts → 5+ offres reçues (concurrence saine)

- 5 pts → Montant > 20M € (complexité)

- 10 pts → Montant < 50k € (peu intéressant)

Estimation des économies

Pour les marchés à score ≥70 : estimation conservatrice de 15–35% de réduction possible. Pour les scores 50–69 : 10–25%. Ces estimations ne tiennent pas compte des exigences réglementaires spécifiques (certifications, origine, normes) qui peuvent justifier une partie des surcoûts.

Limites

  • 89,8% des marchés n’indiquent pas le nombre d’offres → le niveau de concurrence réel est largement inconnu
  • Les montants DECP sont globaux (pas de détail par ligne) → impossible de calculer un prix unitaire précis
  • Certains marchés « sans concurrence » sont légalement justifiés (droits exclusifs, urgence impérieuse)
  • Échantillon de 10 000 marchés sur 702 918 disponibles (1,4%)
